# CEUMAP

Protótipo local para apresentar mapas visuais estáticos e uma rota previamente definida para orientação no CEUMA.

## Escopo atual

- Front-end planejado em React + TypeScript, com Vite.
- Planta e mapas estáticos previstos em `public/mapas/`.
- Percurso interno será representado visualmente sobre a planta, depois de validado.
- Sem backend de aplicação, GPS, interatividade ou cálculo automático de rotas nesta etapa.
- Um mapa externo baseado no Google Maps, se utilizado, depende de internet.

A organização inicial de pastas, decisões de arquitetura e dependências gerais estão descritas em [`docs/arquitetura.md`](docs/arquitetura.md). Esta etapa prepara a estrutura do repositório; ainda não há componentes, telas, lógica específica nem arquivos de configuração para executar a aplicação.
